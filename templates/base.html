Usage Guide

SPA Mode (Static Files)

Open index.html directly in any browser or serve via any HTTP server. No backend required.

Query Parameters:

  • Any ?key=value pairs are displayed in the "Incoming Parameters" table
  • ?user_qry=<id> - Lookup user by numeric ID (1-10)
  • ?user_qry_txt=<id> - Lookup user by text ID

Web Service Mode (Flask/Python)

Requires Python 3.11+ and Flask. Run the server:

python app.py

Endpoints:

  • GET / - Dashboard with query parameter support
  • GET /users/<id> - REST API returning JSON user data
  • GET /spa - Serves standalone SPA mode
